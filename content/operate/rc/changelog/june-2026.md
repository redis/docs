## New features

### Billing Admin API access

Users with the [Billing Admin role](/content/operate/rc/security/access-control/access-management.md#team-management-roles) can now use the [Redis Cloud REST API](/content/operate/rc/api/_index.md) to perform billing operations. See [Team management roles](/content/operate/rc/security/access-control/access-management.md#team-management-roles) for the full list of permissions for each role.

### Redis Data Integration 

[Redis Data Integration (RDI)](/content/operate/rc/rdi/_index.md) is now generally available on Redis Cloud. RDI lets you create data pipelines that ingest data from a supported primary database into Redis, so your cache stays in sync with live data and is always ready for queries.

See [Data Integration](/content/operate/rc/rdi/_index.md) to learn how to set up data pipelines with Redis Cloud.
