## Highlights

This is a maintenance release to support [Redis Software 8.2.6](/content/operate/rs/release-notes/rs-8-2-releases/_index.md) version 8.2.6-58. This release includes a fix for CVE-2026-39821. For details, see the [Redis Software 8.2.6-58 release notes](/content/operate/rs/release-notes/rs-8-2-releases/rs-8-2-6-58.md). For API changes, supported distributions, and known limitations, see the [release notes for 8.2.6-21 (October 2026)](/content/operate/kubernetes/release-notes/8-2-6-releases/8-2-6-21-october2026.md).
