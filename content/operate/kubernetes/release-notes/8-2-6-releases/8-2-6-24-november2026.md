## Highlights

This is a maintenance release to support [Redis Software 8.2.6](/content/operate/rs/release-notes/rs-8-2-releases/_index.md) version 8.2.6-52. This release includes a fix for CVE-2026-111497 (critical severity). For details, see the [Redis Software 8.2.6-52 release notes](/content/operate/rs/release-notes/rs-8-2-releases/rs-8-2-6-52.md). For API changes, supported distributions, and known limitations, see the [release notes for 8.2.6-21 (October 2026)](/content/operate/kubernetes/release-notes/8-2-6-releases/8-2-6-21-october2026.md).

## Downloads

- **Redis Enterprise**: `redislabs/redis:8.2.6-52.24` (`redislabs/redis:8.2.6-52.24.minimal` for minimal base image)
- **Operator**: `redislabs/operator:8.2.6-24`
- **Services Rigger**: `redislabs/k8s-controller:8.2.6-24`
- **Call Home Client**: `redislabs/re-call-home-client:8.2.6-24`

## Known limitations

### New limitations

- **Upgrading to 8.2.6-24 on OpenShift from Redis Software for Kubernetes 8.0.20-31, 7.22.2-51, or 7.8.6-24 is not supported.** To move to 8.2.6 from those versions, upgrade to a version later than 8.2.6-24.

See the [release notes for 8.2.6-21 (October 2026)](/content/operate/kubernetes/release-notes/8-2-6-releases/8-2-6-21-october2026.md#known-limitations) for information on other known limitations.
