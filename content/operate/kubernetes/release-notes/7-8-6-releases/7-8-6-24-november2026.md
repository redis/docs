Redis Software for Kubernetes 7.8.6-24 (November 2026) is a maintenance release that includes support for [Redis Software 7.8.6-351](/content/operate/rs/release-notes/rs-7-8-releases/_index.md). This release includes a fix for CVE-2026-111497 (critical severity). For details, see the [Redis Software 7.8.6-351 release notes](/content/operate/rs/release-notes/rs-7-8-releases/rs-7-8-6-351.md).

For supported distributions, known limitations, and API changes, see [Redis Software for Kubernetes 7.8.6-1 March 2025 release notes](/content/operate/kubernetes/release-notes/7-8-6-releases/7-8-6-1-march2025.md).

## Downloads

- **Redis Enterprise**: `redislabs/redis:7.8.6-351`
- **Operator**: `redislabs/operator:7.8.6-24`
- **Services Rigger**: `redislabs/k8s-controller:7.8.6-24`

## Known limitations

### New limitations

- **Upgrading on OpenShift from Redis Software for Kubernetes 7.8.6-24 to 8.2.6-24 or earlier is not supported.** To move to 8.2.6, upgrade to a version later than 8.2.6-24.

See [7.8.6 releases](/content/operate/kubernetes/release-notes/7-8-6-releases/_index.md) for information on other known limitations.
