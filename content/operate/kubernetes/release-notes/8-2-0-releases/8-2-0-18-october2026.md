## Highlights

This is a maintenance release to support [Redis Software 8.2.0](/content/operate/rs/release-notes/rs-8-2-releases/_index.md) version 8.2.0-78. For version changes, supported distributions, and known limitations, see the [release notes for 8.2.0-12 (July 2026)](/content/operate/kubernetes/release-notes/8-2-0-releases/8-2-0-12-july2026.md).

## Enhancements

- Set `runAsNonRoot: true` at the container-level `securityContext` <!--RED-217695-->

## Resolved issues

- Fixed REAADB creation failing with a 406 error when `tlsMode` is `enabled` and the spec doesn't set `clientAuthenticationCertificates` <!--RED-214573-->

- Fixed new REAADBs with `tlsMode: replica_ssl` requiring a client certificate when none is configured <!--RED-215539-->
