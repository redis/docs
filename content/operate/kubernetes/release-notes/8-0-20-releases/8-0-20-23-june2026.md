**This release has been recalled.** Don't install Redis Software for Kubernetes version 8.0.20-23 or upgrade to it. Use [Redis Software for Kubernetes version 8.0.20-25](/content/operate/kubernetes/release-notes/8-0-20-releases/8-0-20-25-july2026.md) or later instead. Version 8.0.20-25 includes [Redis Software version 8.0.20-68](/content/operate/rs/release-notes/rs-8-0-releases/rs-8-0-20-68.md), which fixes an internal certificate issue that can cause upgrades to fail (RS199373).
{{< /banner-article >}}
