Use the self-managed control-plane API to create playbooks and manage their settings and lifecycle. This reference corresponds to chart `0.1.0-alpha.3`.

[Download the OpenAPI contract]({{< relref "/operate/iris/agent-playbook/self-managed/control-plane-api-reference/" >}}openapi-control-plane.json), follow the [administration examples]({{< relref "/operate/iris/agent-playbook/self-managed/api-examples" >}}), or review [authentication and access]({{< relref "/operate/iris/agent-playbook/self-managed/authentication" >}}).

Application key management belongs to Identity Service. Content authoring, proposals, and retrieval use the [data-plane API]({{< relref "/develop/ai/context-engine/agent-playbook/api-reference" >}}).
