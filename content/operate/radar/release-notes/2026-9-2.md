Redis Radar's first generally available release. Radar gives you one fleet-wide view of every Redis cluster you run.

This is a Short-Term Support (STS) release. See [Self-managed releases]({{< relref "/operate/radar/release-notes" >}}#self-managed-releases) for more details.

## Features

- **Fleet visibility.** Connect and monitor **Redis Software**, **Redis Cloud**, **Redis Open Source**, **Amazon ElastiCache**, and **Google Memorystore** clusters from a single view. ElastiCache and Memorystore connections are off by default; an administrator turns them on. See [Connect clusters]({{< relref "/operate/radar/connect" >}}).
- **Views.** Five dedicated views: **Overview**, **Clusters**, **Databases**, **Usage**, and **Alerts**. See [Monitor clusters and databases]({{< relref "/operate/radar/monitor" >}}).
- **Cross-cluster database list.** A cross-cluster **Databases** list, so you can find a database without knowing which cluster it lives on, including Active-Active replication health.
- **Usage tracking.** Memory, ops/sec, and shard consumption against licensed limits for Redis Software.
- **Alerts.** Aggregated from every connected Redis Software cluster and node, ordered by severity, with rules that stay owned by the cluster.
- **License tracking.** Fleet-wide **license** tracking: expiration date, days remaining, and shard usage broken out by total, RAM, and Flex shards, with CSV export.
- **Certificate tracking.** Fleet-wide **certificate** tracking by type, with expiration dates and a shared Valid/Expiring/Expired status model. See [Licenses and certificates]({{< relref "/operate/radar/licenses-and-certificates" >}}).
- **Local accounts.** Local accounts with two roles, administrator and viewer, plus account lockout and unlock.
- **LDAP.** Integration with group-to-role mapping.
- **SAML SSO.** Includes enforced SSO and email-domain restriction options.
- **FIPS 140-3.** Validated cryptography available as a separate build.
- **Credential encryption key.** A credential encryption key you control, wrapping every stored connection credential. See [Manage access]({{< relref "/operate/radar/manage-access" >}}).
- **Install methods.** Two install methods — **RPM** (RHEL 9) and **Helm** (Kubernetes and OpenShift) — from the same release artifacts.
- **Air-gapped installation.** Air-gapped installation supported for both methods. See [Install Radar]({{< relref "/operate/radar/install" >}}).
