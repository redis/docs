Use the Redis Intent Router data-plane API to author intents and examples and to match queries against a Router. Operations are scoped to one Router by its `routerId`.

[Download the OpenAPI contract]({{< relref "/develop/ai/context-engine/intent-router/api-reference/" >}}openapi.json) to generate clients or inspect schemas.

See [Redis Intent Router concepts](/content/develop/ai/context-engine/intent-router/concepts.md) for Routers, intents, and scores, [Match queries](/content/develop/ai/context-engine/intent-router/match.md) for thresholds, and [service limits and errors](/content/develop/ai/context-engine/intent-router/limits.md) for constraints and recovery.
