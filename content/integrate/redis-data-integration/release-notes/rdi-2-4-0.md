## What's New in 2.4.0

### Breaking Changes

See [Upgrading to RDI 2.4.0](/content/integrate/redis-data-integration/installation/upgrade.md#upgrading-to-rdi-240) for the breaking changes and the steps to take before and after you upgrade.

- Oracle sources ignore the LogMiner batch, sleep, and SCN gap detection properties that Debezium 3.7 removed.
- Oracle sources hold shared locks on the captured tables until the initial snapshot finishes, and ignore `snapshot.database.errors.max.retries`.
- MySQL and MariaDB sources no longer accept `snapshot.mode: never`.
- MySQL sources parse DDL statements with a new parser.
- MariaDB sources take MariaDB values for `database.ssl.mode`, for example `verify-ca` instead of `verify_ca`. See [Update the database.ssl.mode values of MariaDB sources](/content/integrate/redis-data-integration/installation/upgrade.md#update-the-databasesslmode-values-of-mariadb-sources).
- The `GET /api/v2/pipelines/{name}/source-schemas/{source_name}` endpoint returns PostgreSQL user defined column types without their schema, for example `geometry` instead of `"inventory"."geometry"`.
- SQL Server updates report a placeholder as the previous value of an unchanged large column. See [Check SQL Server jobs that read previous values](/content/integrate/redis-data-integration/installation/upgrade.md#check-sql-server-jobs-that-read-previous-values).

### Improvements

- **Debezium upgrade**: Upgraded Debezium from version 3.5.0 to version 3.7.1.
- **Debezium heartbeats on by default**: The Debezium collector now sends a heartbeat every 60 seconds for MySQL, MariaDB, Oracle, PostgreSQL, SQL Server, and MongoDB sources. Set `heartbeat.interval.ms` in `sources.<name>.advanced.source` to change the interval, or to `0` to turn heartbeats off. If you set `heartbeat.action.query` for a source without `heartbeat.interval.ms`, RDI now runs the query every 60 seconds. See [Review the heartbeat settings of your sources](/content/integrate/redis-data-integration/installation/upgrade.md#review-the-heartbeat-settings-of-your-sources).
