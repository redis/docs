## What's New in 2.4.0

### Breaking Changes

See [Upgrading to RDI 2.4.0](/content/integrate/redis-data-integration/installation/upgrade.md#upgrading-to-rdi-240) for the breaking changes and the steps to take before and after you upgrade.

- **Oracle LogMiner batch and sleep properties are no longer supported**: Configuration validation now rejects `log.mining.batch.size.*`, `log.mining.sleep.time.*`, `log.mining.scn.gap.detection.*`, `log.mining.continuous.mine`, `log.mining.buffer.infinispan.cache.rollbacks`, and `log.mining.buffer.ehcache.rollbacks.config` in `sources.<name>.advanced.source`, and running collectors ignore them. Remove them before redeploying the pipeline configuration, and tune `log.mining.log.count.min` and `log.mining.log.count.growth.max` instead.
- **MySQL and MariaDB sources no longer support `snapshot.mode: never`, and parse DDL statements with a new parser**: A source with `snapshot.mode: never` fails at startup, so check whether `no_data`, which skips the initial snapshot, works for your case. In addition, if a source fails on a DDL statement that it parsed before, set `ddl.parser.type: legacy` in `sources.<name>.advanced.source`.
- **MariaDB sources take MariaDB `database.ssl.mode` values**: Replace `disabled` and `preferred` with `disable`, `required` with `trust`, `verify_ca` with `verify-ca`, and `verify_identity` with `verify-full`. The default is now `disable`.
- **PostgreSQL user defined types are reported without their schema**: For example, a column type is now `geometry` instead of `"inventory"."geometry"`.
- **SQL Server sources report unchanged large columns with a placeholder**: In update events, unchanged `VARCHAR(MAX)`, `NVARCHAR(MAX)`, and `VARBINARY(MAX)` columns now contain the value of `unavailable.value.placeholder` instead of `NULL`.
- **`poll.interval.ms` values above 5 seconds are applied as set**: Earlier versions capped the poll interval at 5 seconds.

### Compatibility Notes

- **Oracle `redo_log_catalog` mining strategy is deprecated**: Debezium 3.7 still accepts `log.mining.strategy: redo_log_catalog`, but plans to remove it. Use the default `online_catalog`, or `hybrid` if `lob.enabled` is not set to `true`.

### Improvements

- **Debezium upgrade**: Upgraded Debezium to version 3.7.0.
