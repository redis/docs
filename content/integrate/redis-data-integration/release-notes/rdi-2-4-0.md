## What's New in 2.4.0

### Breaking Changes

See [Upgrading to RDI 2.4.0](/content/integrate/redis-data-integration/installation/upgrade.md#upgrading-to-rdi-240) for the breaking changes and the steps to take before and after you upgrade.

- Oracle sources reject the LogMiner batch, sleep, and SCN gap detection properties that Debezium 3.7 removed.
- MySQL and MariaDB sources no longer accept `snapshot.mode: never`, and parse DDL statements with a new parser.
- MariaDB sources take MariaDB values for `database.ssl.mode`.
- PostgreSQL user defined types are reported without their schema.

### Improvements

- **Debezium upgrade**: Upgraded Debezium to version 3.7.0.
