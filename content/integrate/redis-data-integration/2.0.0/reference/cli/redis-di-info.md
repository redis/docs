Displays information about the RDI deployment, such as the RDI version reported by the API.

## Usage

```
redis-di info [flags]
```

## Options

This command takes only the
[global options](/content/integrate/redis-data-integration/2.0.0/reference/cli/redis-di.md#global-options).
