These examples continue from the [quickstart]({{< relref "/develop/ai/context-engine/agent-memory/quickstart" >}}). Reuse its client, connection values, and user ID.

- **Python:** Add each snippet inside the `with` block in `main`.
- **TypeScript:** Add each snippet inside `run`.
- **curl:** Use the shell where you exported the connection values.

Each run executes every write still in the file. Comment out completed writes and their output statements before rerunning it. Repeating a session-event write can add the same message again.
