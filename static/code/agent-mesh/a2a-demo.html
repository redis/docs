Reconnect without missing updates

A simulated agent produces 20 updates, one per second. Disconnect your subscription, wait a few seconds, and reconnect. The agent keeps working while you are away.

    The page saves each event cursor after applying its update. Reconnect uses ?after= to request the retained events after that cursor. The browser's native EventSource receives the stream.

    Local demonstration only. There is no sign-in: all requests use one fixed demo owner. Closing a subscription does not cancel agent execution. Replay depends on retained Redis history.
